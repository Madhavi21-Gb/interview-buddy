# 🎯 Interview Buddy

A responsive React-based web application designed to help users manage and review interview-related submissions efficiently.

---

## 🚀 Live Demo
🔗 [Click here to view the live site](https://Madhavi21-Gb.github.io/interview-buddy)

---

## 🧠 Overview
**Interview Buddy** is a student-friendly platform where users can:
- View, review, and grade interview submissions  
- Filter and sort submissions by criteria  
- Maintain responsive UI across desktop and mobile devices
